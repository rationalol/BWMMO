# Content localization

`zh_CN/names.json` is generated by `tools/fetch_pokeapi_zh.mjs`.

- `species`: generated from PokeAPI GraphQL `zh-hans` names, keyed by content species id.
- `moves`: generated from PokeAPI GraphQL `zh-hans` names, keyed by content move id.
- `items`: generated from PokeAPI REST item names, keyed by content item id.
- `shops`, `maps`: keyed by content id; map/NPC translations use the project glossary.
- `locations`: English names from the ROM outdoor matrix (field 14 of the zone header) to display names; the grid itself is `content/rom/outdoor_locations.json`.
- `npcs`: keyed by the English NPC name from the map files.

Names are display-only. The server keeps canonical English names in saves and
only replaces them on outbound client payloads, so switching languages never
mutates persisted characters.

Regenerate after changing content or the glossary:

```bash
node tools/fetch_pokeapi_zh.mjs
```

The script caches GraphQL and item responses under `.tools/pokeapi-cache/`.
